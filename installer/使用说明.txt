日报越狱 · 使用说明
====================

它是什么：每天 18:00 自动把你今天真正改了的代码整理成日报，提交到公司的日报系统。
（读你电脑上的 git / SVN 提交和 Claude Code / Codex 的对话记录，用你电脑上已有的 AI 写成日报。）

一、安装
  1. 先把压缩包完整解压（不要在压缩包里直接运行）。
  2. 双击「安装.bat」。如果 Windows 提示「已保护你的电脑」，点「更多信息」→「仍要运行」
     （因为软件没有买代码签名证书，杀毒软件偶尔也会提示，选允许即可）。
  3. 装好后会在桌面和开始菜单生成「日报越狱」，并问你要不要开机自启（推荐）。

二、使用前提
  - 这台电脑上装有 Claude Code 或 Codex（任一个就行），并且已经登录能用。
    软件会自己找，命令行、桌面版、VS Code / Cursor 插件里的都行。
  - 能访问公司日报系统（需要的话先连公司网络 / VPN）。
  - 可选：装了 git，或 SVN 的命令行（svn.exe），就能读到提交记录。

三、第一次打开
  只会让你做一件事：登记日报系统的账号密码（只存在这台电脑的 Windows 凭据管理器里，不上传）。
  项目、任务类型、汇报人等会自动沿用你上一份日报里的选择，不用设置。

四、平时
  - 17:30 自动出日报草稿，你可以打开软件看一眼、直接改；18:00 自动提交，提交后弹窗告诉你交了什么。
  - 没写代码的活（开会、讲方案）在首页「补一句手记」里写一句，软件会把它算进日报。
  - 私人项目：在「认罪书 → 依据记录」里把那个仓库选成「不上报」，它的内容不会进日报，也不会发给 AI。
  - 关掉窗口只是缩进右下角托盘；要真正退出：托盘图标右键 →「保外就医（退出）」。
  - 软件开着（或开机自启）时才会自动提交；电脑关机 / 软件没开，到点就不会交。

五、卸载
  双击「卸载.bat」，或在「设置 → 应用 → 已安装的应用」里卸载「日报越狱」。
  卸载会保留你的设置和日报数据（不会丢），想彻底清掉的位置会在卸载时告诉你。

六、出问题怎么办
  - 打不开窗口：多半是缺 WebView2 运行时，安装 https://go.microsoft.com/fwlink/p/?LinkId=2124703 （微软官方，约 2MB）。
  - 日志文件：%APPDATA%\daily-prison\app.log （把它发给开发者就能查原因）。
  - 软件里「典狱长办公室」→「装备」能检测 Claude / Codex 找到没有、能不能用。
